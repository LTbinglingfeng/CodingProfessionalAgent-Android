# 连接 CPA 桌面端

先在 CPA 桌面端开启 Web 服务，再在 Android 应用里打开「设置 → 添加连接」。

## 直连

- 手机与桌面需网络可达。真机填写桌面的局域网地址；Android 模拟器访问开发机通常用 `10.0.2.2`。
- Android 17 起，访问局域网前需要授予应用本地网络权限。
- 地址未写协议时按 HTTP 处理。使用 HTTP 时须在连接编辑器单独确认，修改地址后需重新确认。HTTP/WS 会明文传输数据和口令，请勿在不可信网络使用；HTTPS/WSS 会验证证书。不要在缺少可靠访问控制时将桌面服务暴露到公网。

## 共享隧道

选择隧道，填写网关地址和凭据，从发现列表选择桌面，再保存桌面登录信息。网关凭据与桌面口令是两套独立凭据。

## 凭据与重连

- 连接凭据保存在 Android Keystore 保护的加密存储中。编辑时密码留空会保留旧值，明确勾选清空才会删除密码。
- 回到前台时应用会重连并同步；退出页面不会关闭共享连接，进入后台会释放 socket。
- 如果操作结果未知，应用不会自动重发。请先刷新会话、在桌面核对状态，再决定是否重试。
